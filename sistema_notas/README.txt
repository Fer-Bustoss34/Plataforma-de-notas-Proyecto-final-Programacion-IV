# Sistema de Notas

## Requisitos
- Java 25 instalado

## Cómo correr el proyecto
1. Clonar el repositorio
2. Abrir NetBeans
3. File → Open Project → seleccionar la carpeta del proyecto
4. Clic derecho → Clean and Build
5. Presionar Play (F6)
